# 🚀 LedgerLine

![LedgerLine Dashboard UI](Screenshot%202026-11-06%20144912.png)

LedgerLine is a modern, full-stack ledger and transaction management application. It provides a seamless interface for managing accounts and tracking daily ledger entries with a robust backend architecture.

## 🛠️ Tech Stack

### Frontend
* **Framework:** React.js with Vite
* **Styling:** Tailwind CSS
* **Architecture:** Component-based UI

### Backend
* **Framework:** Spring Boot (Java)
* **Build Tool:** Maven
* **Architecture:** RESTful APIs (Controllers, Services, Repositories)

## 📁 Project Structure

This repository is organized as a monorepo containing both frontend and backend codebases:

* `/frontend` - Contains the React + Vite frontend application.
* `/ledgerline` - Contains the Spring Boot backend application.

## ✨ Key Features (Ongoing)
* **Account Management:** Create and manage user accounts.
* **Transaction Tracking:** Record and monitor ledger entries.
* **Modern UI:** Fast and responsive user interface powered by Vite and Tailwind CSS.
* **API Integration:** Real-time data fetching between React and Spring Boot.
